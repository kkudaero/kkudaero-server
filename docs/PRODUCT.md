# 꾸대로(kkudaero) 제품 개요

에이전트와 개발자가 작업 전에 읽는 제품 요약입니다. 자세한 기획 배경은 기획서(Claude Docs)에 있고, 이 문서는 현재 확정된 결정만 담습니다.

## 한 줄 정의

일본 구매대행을 처음 시작하는 1인 사업자가 첫 주문부터 통관까지 혼자 헤매지 않게 해주는 웹 도구. 셀러가 성장하면 주문 관리, 스마트스토어 연동, 중국 지원으로 확장한다.

## 원칙

- **교육이 아니라 도구다.** 강의·컨설팅을 하지 않는다. 공식 자료(관세청, 스마트스토어 공지) 기반 체크리스트와 계산기, 알림, 매뉴얼을 제공한다.
- **긴급 대응은 자동화 + 커뮤니티로 한다.** 통관 상태 알림과 상황별 매뉴얼을 제공하고, 오픈채팅은 셀러끼리 돕는 공간으로 둔다. 1:1 실시간 상담은 하지 않는다.
- **통관 신고 대행은 하지 않는다**(관세사 업무). 관부가세는 언제나 "예상치"로 보여 준다.
- **웹이 본체, iOS 앱은 보조다.** 웹만으로 모든 기능을 쓸 수 있어야 한다.
- **운영자는 직접 판매하지 않는다.** 실사용 검증은 인터뷰한 파트너 셀러가 맡는다.

## 저장소

| 저장소 | 공개 | 역할 |
|---|---|---|
| `kkudaero-server` | private | Spring Boot(Java 21) API 서버. 계산, 콘텐츠, 외부 API, 개인정보 |
| `kkudaero-web` | public 예정 | Next.js 셀러용 웹 |
| `kkudaero-ios` | public 예정 | SwiftUI 보조 앱(알림, 송장 입력, 빠른 계산) |
| `.github` | public | organization 소개 |

웹과 iOS는 서버의 OpenAPI 명세(`/v3/api-docs`)로 타입을 만든다.

## 로드맵

1. **0단계 — 검증과 자료 정리**: 셀러 10~20명 인터뷰, 디자인 파트너 3~5명. 체크리스트·매뉴얼은 공식 자료로 쓰고 경력 셀러(가능하면 관세사)에게 검수받는다.
2. **1단계 — 무료 웹 도구(일본 전용, 네이버 API 없음)**
   - 시작 체크리스트: 사업자등록 → 통신판매업 신고 → 관세청 전자상거래업자부호 → 스마트스토어 해외상품 판매권한 → 배대지
   - 관부가세·마진 예상 계산기: 150달러 목록통관 판정, 합산과세 경고
   - 통관 진행 조회·알림: 관세청 화물통관 진행정보 공개 API
   - 상황별 대응 매뉴얼과 고객 안내 문구: 통관 보류, 개인통관고유부호 오류·만료, 해외 품절, 배송 지연·파손
   - 수동 입력 주문 추적 보드
3. **2단계 — 커뮤니티**: 오픈채팅·카페로 사용자 모으기, 질문을 매뉴얼에 반영.
4. **3단계 — 유료화**: 사업자 등록 후 주문 관리(스마트스토어 주문 엑셀 연동) 유료 기능, 자체 결제.
5. **4단계 — 확장**: 법인 설립 후 네이버 커머스솔루션마켓 '주문·배송' 솔루션 입점, 중국 지원, iOS 앱.

## 도메인 기준값 (바뀔 수 있으니 한곳에서 관리)

- 목록통관: 개인 자가사용 + 물품가격 미화 150달러 이하(일본·중국발). 물품가격에는 현지 내 운임 등이 포함된다.
- 합산과세: 같은 날 같은 판매자에게 산 물품은 합산될 수 있다. 기준은 입항일이 아니라 구매일(결제일).
- 개인통관고유부호: 2026-08-28부터 유효기간 도입. 신규 발급자는 1년, 기존 발급자는 2027년 본인 생일 만료.
- 전자상거래업자부호: 사업자만 발급 가능(관세청 UNIPASS). 2026-11-18부터 스마트스토어 미등록 셀러는 해외상품 판매권한 회수.
- 목록통관 제외 품목: 의약품, 건강기능식품, 화장품 일부, 동식물·식품 등(검역 대상).

## 나중 단계에서 지킬 네이버 정책 (4단계 대비)

- 다른 셀러의 스토어에 API로 접근하려면 커머스솔루션마켓 입점이 필요하다. 입점 동의는 현재 국내 법인만 가능하다(가이드 24.10 기준).
- 입점 불가 기준에 걸리지 않게 설계한다: 외부 공급처 상품을 수집해 대량 등록, 판매자 확인 없는 자동 실행, 자체 추정값으로 판매가 자동 조정, 판매자 데이터 목적 외 이용, 설치형(별도 앱 필수) 솔루션.
- 판매자가 해지하면 판매자·구매자 개인정보와 식별자를 삭제해야 한다.
- 상세 가이드 원문은 `docs/references/naver-commerce-solution/`에 둔다.
